## 用户指定：右下替换茶叶碗

右下原小杯的位置改为装满茉莉茶叶的陶碗，作为原料展示。模板五材料页同款米色斑点陶碗，宽圆碗口、矮圈足，略俯视的斜向碗口；装得饱满的深灰橄榄绿扁长茉莉干茶，夹少量乳白至微黄干花苞，茶堆自然高出碗沿。与原右下模块同一落桌位置，碗宽略大于碗高，最高不挡住第三条纸条，低处不压住底部收藏条。只借用模板五的碗、茶叶形态及朝向，背景、纸条和其他版式继续按模板七。
