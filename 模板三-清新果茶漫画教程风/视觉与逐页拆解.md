## 二、封面

上部约四成画面是白底深绿色描边的不规则爆炸框，内放两行超大刷笔字。第一行用核心动作，第二行用准确产品名；深色字与浅色背景形成强对比。

中下部左侧是一杯被角色举起的成品，右侧是大角色的脸与身体，角色握拳、张口，形成兴奋感。饮品与角色构成同一个主视觉，杯子不能被标题遮住。背景为明亮浅果绿，外围散布真实原料、冰块、水珠和放射线。

可复用骨架：`[核心动作或特点] / [饮品名称]` → 单杯成品＋举杯角色 → 原料与冰块装饰。封面不放长配方、操作卡或材料清单。

## 四、视觉模板

### 画布与层级

- 3∶4竖版；同套图片尺寸一致，四周保留安全边距。
- 标题最大，步骤号次之，正文清晰，台词和标签较短。标题常用粗圆手写字；封面可用更有冲击的刷笔字。
- 白色或奶油白承载正文，深棕写正文，主题深色强调关键词；一句中只强调少量核心词。
- 内容页保留足够文字空间，不用装饰、手臂或器具遮挡文字。

### 色彩与光线

- 原参考主色为浅果绿、草绿、深绿，辅以奶油白、暖木色、亮黄与少量腮红粉。
- 换主题后用饮品原料决定主色：莓果可用莓红，芒果可用金黄，奶茶可用焦糖棕。整套只选一个主色方向、一个深色强调色及少量点缀色。
- 保留明亮自然光、柔和背景虚化、窗边叶影、干净台面和木托盘；成品透明反光、冰块通透、果肉纹理清楚。
- 配色可换，液体和原料仍按真实外观画，不能把果肉、茶汤、所有器具统一染成主色。
- 用户最新反馈要求整体清朗淡雅：优先近白与柔和浅绿、轻透浅金茶汤、简洁窗边场景和留白，减少浓黄暖光、强高光、密集绿植与装饰。封面角色角度、姿态、比例和位置对照指定原图，不因为换角色而自行重排。本期[茉莉绿茶试稿v3](茉莉绿茶/试稿-v3/README.md)采用模板一厨师怪兽，直接参照本轮补发猫咪封面调整。

### 图形语言

云朵框承载清单、台词和情绪标题；爆炸框承载冲击标题或关键卖点；虚线圆角卡承载长说明。细节用圆形放大框，逻辑用弯箭头或两格间箭头，动作配少量运动线。叶片、冰块、水珠、星星围绕主体，不填满所有留白。

### 角色与品牌适配

原参考是白色大头猫、粉色条纹、绿色领巾与围裙。用于「怪兽茶研社」的新内容时，默认沿用[模板二试稿v3](../模板二-奶油手账食谱风/茉莉绿茶/试稿-v3/README.md)的黑色白线怪兽本体：宽短吻部、小角、背刺、白线眼与锯齿嘴、正常两条腿，无完整图标和厨师服饰。用户后续可明确指定其他角色。

沿用v3的是角色外形；模板三的角色是大主角，不沿用模板二的页角小配角位置。举杯、处理食材、双手操作、试饮、坐姿等动作对应参考的位置和情绪。同一套角色比例、线条及外形一致；不把猫耳、猫尾、爪印或猫脸移植到怪兽上。原参考「Tea咪说」在品牌版改为「怪兽说」。

产品与食材偏写实，角色保持平面漫画块面与少量白线。品牌成品杯默认沿用无字透明外带塑料杯及凸起透明饮口盖；制作容器按真实操作选用，不能把外带杯当雪克壶。泡茶及接茶用直筒刻度玻璃壶；涉及过滤时沿用[共享不锈钢滤网规范](../器具规范.md)。

## 五、固定项与替换项

| 保留结构 | 换主题后替换 |
| --- | --- |
| 八页顺序、每页信息位置与标题层级 | 产品名、标题和台词 |
| 封面单杯＋大角色、材料云朵清单、动作大图＋特写 | 原料、用量、真实工具、操作内容 |
| 操作三双格、风味页三卖点卡、收尾留言卡 | 四组真实操作和对应注意点 |
| 窗边自然光、浅色底、深色字、漫画框与箭头 | 主色、饮品颜色、装饰原料 |
| 同套角色一致、无字品牌杯、真实图文对应 | 口感、使用场景、结尾互动 |

新主题先按真实流程分成四组操作；每组可含两个连续子动作，覆盖全部必要步骤。不能为了套八页删去泡茶、计时、过滤或冷却。若真实流程无法合理装入四页，说明需要增加操作页，而不是漏步骤或编造动作。材料数量按实际配方调整，卖点卡不够三项时从真实口感、原料和饮用场景提炼，不虚构效果。

## 六、参考文字与新配方的边界

参考食材页写的是「1杯量」：青柠2—3颗、泡好的绿茶茶汤200ml、冰块满满1杯、冰糖糖浆适量、薄荷叶少许。这些是原参考文字记录，不是对怪兽茶研社既有配方的修改，也不能直接套到新饮品。

- 「暴打」是标题表现；具体捣压力度按真实操作写，不能把不过度捣烂改成持续猛砸。
- 原参考的「冰块中和酸涩」不作为新教程的事实。冰块用于降温，融化可稀释饮品；不能据此写化学中和或保证去苦。
- 「5分钟」「低成本」「健康」「茶店爆款」「完全无苦味」等文字只在真实条件支持时使用。默认用具体香气、口感和制作提示替代。
- 原参考含薄荷，新主题是否加薄荷、柠檬、糖浆或其他配料由真实配方决定。桌面装饰与杯内配料分别列清楚。
- 基底与单杯用量分开；不把批量茶叶50克等旧案例数字搬到这套单杯教程，也不把投料相加写成实际产量。

4. 核对中文、用量、顺序、动作、杯内配料、工具和正常两腿角色。局部错误只改指定区域。
5. 新主题图片另存「主题名/试稿-v1/图片」，按01—08排序，记录真实尺寸、字节数与SHA-256；修订另存新版本，保留旧图。
