# 模板三｜清新果茶漫画教程风

建立日期：2026-10-14（Asia/Shanghai）。来源：用户本轮上传的八张「暴打柠檬绿茶」参考图。

本模板用于换饮品主题后生成同结构的成套图文：封面 → 食材 → 四页操作 → 风味卖点 → 收尾，共八页。与模板一五页、模板二四页独立保存；模板二当前参考仍为试稿v3。

- [视觉与逐页拆解](视觉与逐页拆解.md)：参考图顺序、八页布局、文字层级、色彩与品牌适配。
- [出图提示词](出图提示词.md)：通用画面约束、逐页提示词与局部修改方式。
- [新主题输入模板](新主题输入模板.md)：填写主题、真实配方、四组操作及卖点。

## 快速调用

> 使用「模板三｜清新果茶漫画教程风」。新主题：[饮品名称]。真实配方：[份量、原料、用量、完整步骤、已确认时间与温度]。保留八页结构：封面、食材、四页操作、风味卖点、收尾。角色默认沿用模板二试稿v3的品牌怪兽本体，杯身无字。先组织完整八页文案，再按同一视觉规范逐页生成；未知参数留待确认，不沿用参考饮品的用量。

换主题时保留每页的信息位置、阅读节奏和角色比例，替换产品名、食材、液体颜色、真实操作、主色与卖点。制作页不强制套用柠檬切片、捣压或加糖；按新配方分成四组连贯操作。

沿用当前茉莉绿茶基底时，采用[当前配方](../当前配方.md)：热水70℃，雪克用料为茶汤、糖浆与香水柠檬片，基底750克冰块保留。参考猫咪教程的加冰步骤不作为这份雪克配方。
