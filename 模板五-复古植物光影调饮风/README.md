# 模板五｜复古植物光影调饮风

保存日期：2026-10-15（Asia/Shanghai）。依据用户本轮上传的「经典莫吉托」三张参考，拆解为可更换饮品主题的三页模板。已完成文字模板、提示词及[茉莉绿茶试稿v1三页](茉莉绿茶/试稿-v1/README.md)，按用户要求纳入GitHub版本保存。

## 三页结构

| 页码 | 页面 | 固定结构 |
| --- | --- | --- |
| 01 | 封面：产品与风味 | 左上类别签、左侧书法主标题与手写副标题、短句与简介、四条产品信息、左下故事便签；右侧大杯成品 |
| 02 | 材料清单 | 顶部类别签与标题组合；左中至右中错落陈列真实食材和器具，以短引线标注用量；左下杯型便签 |
| 03 | 制作步骤 | 左上标题、左侧四组编号步骤与对应操作小图、右侧成品大图；左下技巧便签、中下风味信息、右下收尾短句 |

核心不是贴纸漫画，而是奶油米色旧纸、深墨绿文字、真实饮品与食材、木桌、轻微植物光影和复古编辑排版。三页保持同一环境、杯型、光线方向与标题系统。
