# 模板五｜视觉与逐页拆解

## 1. 总体视觉

参考为三张2:3竖版，聊天展示约1024×1536。以下坐标均为人工观察的相对画幅比例，允许按文字长度微调，不是像素测量结果。

- 气质：复古饮品杂志、旅行手札、植物光影；自然真实、安静、有夏日清凉感。
- 底层：奶油米白旧纸或浅砂色墙面，轻微纸纹与极淡地图线稿。避免厚重褐色滤镜、强烈污渍、暗角压黑。
- 右侧：真实成品杯、凝露、透明冰、真实原料；右下有粗纹木桌，纸面与摄影柔和衔接，不用硬矩形照片框。
- 光线：来自左上或左侧的自然侧光，右上棕榈叶及细长叶影；三页光向一致。参考本身偏暖且明暗明显，复用时按用户既有偏好默认减弱阳光与阴影，保留清朗、少量夏日光感。
- 没有白色描边贴纸、Q版人物、六宫格卡片、漫画爆炸框；步骤图可以柔边摄影拼贴，边缘带极淡植物绿晕染。

### 字体与图形

- 中文名称用有笔锋与飞白的书法字，字形厚实，约占页宽40%—60%；不做立体描边或发光。
- 中文类别与正文用清晰宋体／楷意字形；信息标题稍重，正文行距舒展。
- 英文名称为灰橄榄色倾斜手写体，紧贴中文标题下缘；翻译未确认时可省略，不硬塞错误英文。
- 编号01—04为大号斜体衬线数字。步骤间用细直横线，不用圆圈、虚线框或粗箭头。
- 类别签使用单线不规则矩形，信息分隔用细线；图标用深绿圆底浅色线稿。
- 撕边便签只给故事、杯型与技巧，小面积点缀。邮戳、城市线稿与地图属于主题装饰，可替换为新主题真实相关符号或删去。
- 作者签名和账号不复刻。品牌署名如需加入，用用户自己的品牌，位置与强度另定。

## 2. 01封面：左侧信息、右侧成品

| 区域 | 相对位置（x横向／y纵向） | 内容与关系 |
| --- | --- | --- |
| 类别签 | x0—27%，y4—9% | 短类别名，左缘可自然出血 |
| 中文标题 | x4—53%，y11—31% | 参考两行「经典／莫吉托」；新名称按字数分两行或一行，保留视觉重量 |
| 手写副标题 | x5—49%，y29—36% | 产品英文名或短副题，低饱和、次一级 |
| 封面短句 | x5—40%，y37—44% | 两行，细横线上下承接，不写未经确认的制作时长 |
| 风味简介 | x6—39%，y45—51% | 两至三短行，以具体口感描述为主 |
| 产品信息 | x5—37%，y53—74% | 四条：图标＋小标题＋短说明，条间细线 |
| 故事便签 | x3—42%，y74—92% | 小面积浅纸便签；背景故事只用已确认内容 |
| 成品主体 | x47—94%，y26—89% | 高大成品杯，杯口装饰完整，清楚显示杯壁与内容物 |
| 环境层 | 右上、右下、底边 | 上方植物及叶影，右下木桌／食材，底边极淡线稿 |

信息四条参考为「杯型／酒精度／风味／调法」。新主题可等量替换为「杯型／基底／风味／调法」或「份量／甜度／风味／制作方式」，只写确知事实。无酒精茶饮不保留10% ABV；故事没有来源时改成「风味笔记」或「制作要点」，维持便签形状与字量。

## 3. 02材料页：自由陈列，不做网格

| 区域 | 相对位置 | 内容与关系 |
| --- | --- | --- |
| 类别与标题 | x0—63%，y4—31% | 同系列标题；参考「经典」较小、名称一大行，英文下接 |
| 材料清单小标题 | x27—50%，y34—39% | 清晰中文标题＋手画短下划线 |
| 左侧高物件 | x5—24%，y29—73% | 主基底容器／茶壶，形成纵向支点，不强制保留酒瓶 |
| 上中与右中 | x48—67%，y37—56%；x68—94%，y43—65% | 液体小壶、鲜料；避免遮住标题与背景光影 |
| 下中陈列 | x24—57%，y55—82% | 第二液体瓶与量杯，错落高低 |
| 右下陈列 | x58—100%，y66—96% | 冰碗／工具／水果，落在木桌区 |
| 杯型便签 | x15—46%，y80—93% | 小杯线图与杯型名，不算一份原料 |

每项食材旁用短引线标名称、用量及必要备注，字不压在透明玻璃反光里。容器高度、透明度与食材颜色形成节奏。参考约六项原料；新主题数量可调整，但维持左高、中央低、右侧鲜料、下方工具的关系。批量茶汤基底与出品加料需明确分组，不能看起来全是单杯用量。材料多时采用两级小标题及紧凑标注，不编造或删掉必要原料。

| 区域 | 相对位置 | 内容与关系 |

| 标题组合 | x0—47%，y3—26% | 类别签、两行中文主标题、轻手画下划线 |

| 操作图 | x34—56%，y27—78% | 原参考依次拍叶、捣压、加冰、装饰；必须换成新配方的真实动作 |
| 成品大图 | x60—96%，y28—80% | 与封面同杯、同装饰、同饮品状态 |
| 技巧便签 | x5—30%，y78—91% | 一条最关键避坑提示，约3—5短行 |
| 信息复述 | x33—63%，y81—93% | 两条图标信息，延续封面字段 |
| 收尾短句 | x65—94%，y90—96% | 两行短句、轻微倾斜、细手画下划线 |

四步是版式分组，不是删减操作的理由。比如茉莉绿茶可分为「称茶焖泡／过滤取汤／加冰搅匀／雪克出品」，温度、时间和用料均读取[当前配方](../当前配方.md)。每组可含必要子动作，图像不得反画成莫吉托的拍薄荷或捣压。双手操作图应展示正确手势与器具。

## 5. 固定与替换

| 保留的结构 | 随主题替换的内容 |
| --- | --- |
| 三页顺序、2:3比例、左文右图 | 名称、类别、英文名、风味短句 |
| 书法标题与手写副题层级 | 主色点缀、食材、茶汤真实色泽 |
| 侧光、纸纹、木桌及植物阴影 | 配方、份量、杯型、液体容器与工具 |
| 四条封面信息、材料引线、四组步骤 | 步骤动作、参数、技巧、信息字段 |
| 便签和细线语言 | 真实背景故事或替代风味笔记 |

不自动继承朗姆酒、薄荷、苏打水、碎冰小山、古巴地名、邮戳字样、原品牌酒瓶或约10% ABV。怪兽默认不加；如果用户指定，则用独立小品牌形象融入标题或页脚留白，不能挡字或站在产品杯上。

## 6. 生成核对

先定三页文字与新主题配方，再做封面确认主色、杯型、环境与光线；材料页、步骤页沿用同一视觉锚点。逐页核对所有原料用量、单位、顺序、图文操作、透明杯内物、字段和页间一致性。产品不乱加花叶，装饰与实际杯内原料区分。图片按页保存新版本，保留旧版及生成记录。没有实际生成图片时，状态只写「模板规范已保存」。

## 最新统一规则：茶山与器具

用户已要求模板五当前所有页面采用v13材料页左下的中国茶山：淡灰褐细线版画、层叠茶垄、远山薄雾和极小茶亭，融合米白纸底。封面、材料、步骤三页均使用同款装饰，保留各自原位置占比；不再生成欧式城市或海港风景。旧版本图片保留不覆盖。

制作步骤页用具以v13材料清单页为外形依据：热水壶与接茶／加冰搅拌容器采用高直圆筒透明刻度玻璃壶、小倒水嘴、大弧形玻璃把手；焖泡操作保留盖上10分钟，可配薄透明盖，不回用木盖矮胖壶。滤网为圆宽钢边、浅碗细金属网、双线细长U闭环柄。雪克壶为透明刻度壶身和金属三件式密封盖、小顶帽，双手握盖和托底；壶内不画独立冰块。按动作所需缩放并调整持握，不改变步骤文字或将材料静物整张搬进步骤栏。

## 最新统一规则：横向标题

按用户最新指定，模板五当前三页主标题统一为「茉莉绿茶」四个等大深墨绿书法字，同一行横排；灰橄榄色Jasmine Green Tea手写英文紧接下方。覆盖前文参考中两行或分级标题的默认排法。新主题沿用单行标题与下方英文的层级，按名称长度适配字宽与留白，不自动拆成两行。类别签、正文、产品及器具位置不因标题变化重排。中国茶山与同款器具规则继续生效，旧图不覆盖。

## 最新统一规则：原莫吉托底色与质感

当前三页底色、色调与材质统一参照用户最初莫吉托原图：低饱和暖米灰／浅亚麻纸底、带橄榄灰气息的柔和阴影、自然深墨绿与灰棕木桌，细腻纸纹和轻胶片颗粒。避免后续生成中的蜜黄橙色滤镜、过亮塑料CG高光、厚裂纹与油画刷痕。保留真实侧光和叶影位置、亮暗层次，不自动添加光束或横向台面。产品真实淡金茶色仍保留，不能因调色更换配料。该规则应用到当前三页与后续新主题；历史版本文件不覆盖。

材料页补充：用户认为v16色调过重，后续以v17自然浅米灰为准，避免灰褐滤镜和过强颗粒；热水必须为无色清澈纯水，不因暖色调渲染成茶色或浑浊灰液体。

冰块不得带黑点、黑孔或杂质；画普通清透方冰，保留自然浅色折射。
