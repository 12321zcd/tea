## 本期茶汤基底配方

最新配方见[当前配方](当前配方.md)。配方文字已更新；模板一与模板二旧图片尚未同步70℃与糖浆雪克用料，模板三茉莉绿茶清新试稿v2已体现最新配方。

1. 称取茶叶50克。
2. 加入1250克、70℃热水，盖上焖泡10分钟。
3. 用不锈钢滤网过滤茶渣，取出茶汤。
4. 倒入750克冰块，搅拌均匀后可用。

茶叶∶热水∶冰块＝1∶25∶15，按重量配比。雪克用料为茶汤、糖浆、绿色香水柠檬片；雪克步骤中的冰块已改为糖浆，基底750克冰块保留。

这是批量茶汤基底配方。热水温度已确认为70℃；单杯茶汤、糖浆及香水柠檬用量尚未提供。

## 已确认视觉偏好（模板一）

- 怪兽使用稍扁平的漫画风，保持黑色轮廓、白色细节和同一角色外形，减少绒毛质感及立体阴影。
- 成品杯沿用透明外带塑料杯和凸起透明饮口盖，所有杯身无文字或标志。
- 柠檬使用绿皮香水柠檬，淡黄果肉；封面产品名写「今日茶研｜茉莉绿茶」。
- 泡茶及接茶器具使用直筒刻度透明玻璃壶；过滤使用圆形宽钢边、浅碗形细密金属网篮、双线长环柄的不锈钢滤网。
- 五页结构为封面、原料、完整步骤、关键动作、成品收尾。步骤格数按真实配方安排。
- 本版怪兽以指定五图中的圆润漫画厨师形象为准；封面无制作小窗及比例条，原料页保留基底比例，步骤页默认四格，雪克页无底部比例条，封底保留三格表情与完整配方卡。
