## 已确认配方

1. 称取茶叶50克。
2. 加热水1250克，盖上焖泡10分钟。
3. 用红柄布滤袋过滤茶渣，取出茶汤。
4. 倒入冰块750克，搅拌均匀。

茶叶∶热水∶冰块＝1∶25∶15，按重量配比。出品加入绿皮香水柠檬片，双手雪克摇匀。单杯用量、柠檬用量、水温、雪克时间／次数及实际产量未确认。
